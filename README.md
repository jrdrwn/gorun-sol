An adaptive RSI dip-buyer for the Solana bars-replay competition. It buys sharp dips (14-bar RSI below 25, or below 40 in a clear uptrend), sells on +2% take-profit, -3% stop-loss, or after 8 bars, sits in cash when the universe is down more than 8% over 24 hours, and tops up to the 8-trade minimum with tiny $25 probe round-trips. No lookahead, no clock, no randomness: every decision comes from the bars already delivered.

## Run it

```sh
node main.ts
```
